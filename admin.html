Sign in with a GitHub token so this page can save changes to the website. You only need to do this once per device.

  1. Open GitHub → new fine-grained token.
  2. Give it a name (e.g. samwitchells admin) and choose an expiration.
  3. Under Repository access, choose Only select repositories and pick samwitchells.
  4. Under Permissions, add Contents and set it to Read and write.
  5. Click Generate token, copy it and paste it below.

The token is kept only in this browser and is only ever sent to GitHub.
